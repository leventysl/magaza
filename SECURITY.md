# Güvenlik Politikası

## Güvenlik açığı bildirme
Bir güvenlik açığı bulduysanız lütfen **herkese açık issue açmayın**. GitHub'ın
"Security → Report a vulnerability" (özel bildirim) özelliğini kullanın.
48 saat içinde dönüş yapılır.

## Desteklenen sürümler
Yalnızca en son sürüm güvenlik güncellemesi alır.
